How It Works

Five steps from statement to payout. Zero human involvement at any stage.

01
📝
Statement Posted
A verifiable statement is posted on-chain — science, history, crypto, geography. Anything with a factual answer.
02
⚡
Players Stake GEN
Players stake GEN on TRUE or LIE. Payout odds shift in real time based on how much is staked on each side.
03
🤖
LLMs Research It
5 independent LLM validators access the web, cross-check sources, and vote on the verdict with a confidence score.
04
⚖
Consensus On-Chain
GenLayer's Optimistic Democracy reaches a final verdict. Full reasoning stored on-chain. Immutable. Transparent.
05
💰
Winners Paid Out
Correct stakers split the losing pool proportionally. Payment releases automatically via smart contract. Instant.

Why GenLayer
Only Possible
On GenLayer

Traditional blockchains can hold tokens. GenLayer can judge whether a statement deserves them.

01
🧠
LLM JUDGMENT ON-CHAIN
GenLayer's gl.exec_prompt() lets validators call LLMs directly inside the contract. No oracle. No off-chain API. Pure on-chain intelligence.
02
🌐
LIVE WEB ACCESS
Validators fetch real web pages using gl.get_webpage() to verify facts with live sources during evaluation. The contract browses the internet.
03
⚖
MULTI-VALIDATOR CONSENSUS
5 independent LLM validators run the same evaluation. gl.eq_principle_strict_eq() ensures consensus before any verdict is accepted.
04
⚡
INSTANT AUTO-PAYMENT
gl.transfer() releases the winning pool the moment consensus is reached. No withdrawal, no delay, no trust needed.
